# CSE Stock Performance & Macroeconomic Impact Analysis

Analysis of how Sri Lankan macroeconomic indicators (inflation, USD/LKR 
exchange rate, interest rates) correlate with stock performance across 
four CSE-listed companies: JKH, Commercial Bank, LOLC Holdings, and 
Dialog Axiata (2022–2024).

## Tools
Python (pandas), PostgreSQL, Tableau Public

## Key Insights
- LOLC (leasing/finance) is the most macro-sensitive stock (r=-0.785 
  with exchange rate, 205% volatility)
- DIAL (telecom) is the most stable and defensive (35% volatility)
- Not all companies recovered equally post-crisis, and companies in 
  the same sector can react in opposite directions to the same macro shock
